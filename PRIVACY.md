# Privacy Policy

SnipClip is a clipboard manager and screenshot/annotation tool for macOS. Clipboard and screenshot data can contain sensitive information, so SnipClip never transmits clipboard contents, snippet contents, or captured screenshots to any external service.

## Summary

- SnipClip does not ask users to provide names, email addresses, account information, or other directly identifying personal information.
- SnipClip performs no network communication. There is no analytics, no crash reporting, and no update-check service (unlike the upstream Clipy project this fork is based on, which used Firebase and Sparkle for those purposes — both were removed in this fork).
- Clipboard contents, snippets, and screenshots are stored locally only.

## Data Stored Locally

SnipClip stores clipboard history, snippets, preferences, and pinned/saved screenshots locally on your Mac. None of this data is sent anywhere.

Clipboard managers can retain sensitive information locally. We recommend excluding password managers and other sensitive apps from SnipClip's history recording (Preferences → Exclude App) when relevant.

SnipClip does not encrypt locally stored data. If your Mac contains sensitive data, enable FileVault and use macOS's built-in security features.

## Network Communication

None. SnipClip does not check for updates, does not report usage or crashes, and does not otherwise contact any server.

## Changes

This privacy policy may be updated if SnipClip's behavior changes.
